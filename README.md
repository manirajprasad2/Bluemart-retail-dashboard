# Bluemart-retail-dashboard
I recently finished a Retail Analytics project on BlueMart, a UAE retailer with 50 stores and 200 products, covering Jan 2021 to Oct 2025.  The analysis is done in Python (pandas, NumPy, Matplotlib). But a notebook is not what a manager reads, so I built a one-page interactive dashboard that answers one question: what does management need to know?
